# 星星连连

为手机碎片时间制作的中文益智闯关游戏。地铁是使用场景，游戏为星空连线主题。

点击格子顺时针旋转连线，从金色起点点亮全部星点即可过关。36 关分成 3×3、4×4、5×5 三章；前三关固定大部分格子，方便上手。提供轻松、标准、挑战三档难度（默认标准），各关旋转次数上限随关卡和难度变化。支持提示、撤销、重玩、星级记录和逐关解锁。没有计时、广告、付费项或声音。游客可直接玩，进度存在本机；新增的账号版本支持邮箱登录、云端进度与闯关历史。

## 使用

- 源码仓库：[GitHub · 星星连连](https://github.com/18311149760/-)。在线游戏由现有 Netlify 项目运行，仓库用于保存和管理源码。
- 正式游玩入口：[打开星星连连](https://superlative-begonia-d0e9d9.netlify.app/)，任何人可访问，无需登录或密码。
- 电脑：用浏览器打开 `outputs/星星连连-离线版.html`，单个文件即可运行。
- iPhone：用 Safari 打开正式网址，从共享菜单选择“添加到主屏幕”。添加后先从主屏幕图标联网打开一次，等底部出现“已备好离线游玩”，再离线使用。不要用“文件”App 的 HTML 预览代替手机安装。清理浏览器数据会移除存档和离线缓存。
- 本地预览：`npm run dev`，服务打印地址后打开。`localhost` 链接只能在这台电脑使用。

分享方式为公开网页链接；直接游玩无需登录，登录用于个人云端存档。公开发布已获用户确认。

## 难度与次数

每点击一个可旋转格子扣 1 次；固定格子不扣次数。提示会转好一格，扣除实际旋转次数（1–3 次），按钮提前显示花费。剩余次数不足时提示不执行、不扣次数。撤销只恢复棋盘，不退次数。最后一次旋转恰好完成时判定通关；次数用尽仍未完成时锁定操作，提供重试或降低难度。

设该关已知解的参考旋转次数为 P，棋盘边长为 N：

| 难度 | 每关上限 | 第 1 关 | 第 13 关 | 第 36 关 |
| --- | --- | --- | --- | --- |
| 轻松 | 2P + N | 7 | 42 | 93 |
| 标准 | ceil(1.5P) + max(2, floor(N/2)) | 5 | 31 | 68 |
| 挑战 | P + max(1, ceil(0.2P)) | 3 | 23 | 53 |

全部 108 个“关卡 × 难度”组合都有足够次数完成已知解。切换难度会确认并重开当前关卡，已解锁关卡、最高星级和其他关卡进度保留；新开的关卡沿用所选难度。旧版存档自动迁移至标准档，原棋盘和成绩保留；原已用次数超出新上限的关卡会进入次数用完状态，可自行重试。

关卡使用固定种子的生成树，先创建连通解再旋转打乱，保证可解。三星标准以已知解的参考旋转次数加容错步数计分，不宣称这个参考解是全局最优解。撤销恢复棋盘，但不清除累计旋转和提示使用次数；重玩会重置本局计数并保留最好成绩。

成功标准：全部 36 关可解，前后关正确解锁，存档可恢复，手机触控不依赖拖动，正式构建包含本地资源且不请求外部字体或游戏服务。检查覆盖 108 个关卡与难度组合的通关、恰好用尽次数通关、耗尽后的操作锁定、提示扣减、撤销、难度切换和存档迁移；并完成类型检查、静态构建、模拟离线验证、macOS Safari 基本操作和离线重开检查，以及正式网址的匿名访问与交互验证。尚未使用真实 iPhone 测试。

## 复用与来源

- 玩法参考 [Simon Tatham 的 Net 规则](https://www.chiark.greenend.org.uk/~sgtatham/puzzles/doc/net.html)：旋转方格连成完整网络。仅参考成熟机制，关卡、游戏代码与视觉独立编写，没有复制其程序代码和素材。原项目仍在维护；不直接嵌入其桌面风格界面，以适配中文、触控和短关卡。
- 采用官方 Sites 项目模板、React、已有的 Shadcn/Base UI 对话框和进度条；图标来自已安装的 Lucide（ISC 许可）。复用现有依赖，避免自制模态框造成焦点和键盘问题。
- 离线缓存使用浏览器标准 [Service Worker](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API)，缓存公开游戏资源，私有账号接口始终请求网络。
- 账号复用官方 [Netlify Identity](https://docs.netlify.com/manage/security/secure-access-to-sites/identity/get-started/) SDK 2.0.0，云存档采用 [Netlify Blobs](https://docs.netlify.com/build/data-and-storage/netlify-blobs/) 11.0.3 的站点级存储、强一致读取与条件写入，两者均为 MIT 许可。沿用已可访问的 Netlify 项目，避免再引入额外后台账号和独立数据库。官方于 2026 年恢复持续支持 Identity；[登录服务无额外费用](https://docs.netlify.com/manage/security/secure-access-to-sites/identity/plans-and-pricing/)，请求、存储与部署仍受现有免费套餐额度限制。

`app/page.tsx` 是游戏界面，`app/globals.css` 是样式，`lib/game.ts` 是关卡与状态逻辑。`outputs/` 放可直接使用的交付物，`work/` 留作本地验证中间文件。
